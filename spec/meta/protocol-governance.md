# Protocol Governance

Protocols are versioned contracts.

## Rules

- Every protocol has a canonical spec.
- Every protocol lists producers, consumers, schemas, compatibility rules, and failure modes.
- Breaking changes require ADR and migration plan.
- Protocols should be tested with contract tests.

## Current Protocol Families

- Cognition packet protocol.
- Cognitive event protocol.
- Memory mutation protocol.
- Context lease protocol.
- Intent lease protocol.
- Governance decision protocol.
- Reasoning trace protocol.
- Evolution proposal protocol.
