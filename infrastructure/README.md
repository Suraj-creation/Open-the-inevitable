# Infrastructure

Deployment, operations, and environment assets live here.

Infrastructure should implement the production posture defined in `spec/infrastructure/`, `spec/deployment/`, `spec/scaling/`, `spec/resilience/`, and related domains.

## Planned Areas

- `docker/` - local containers and compose assets.
- `k8s/` - Kubernetes and multi-region deployment manifests.
- `scripts/` - infrastructure automation scripts.
